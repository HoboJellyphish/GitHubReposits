# MedTrak — Reference Documentation

MedTrak is a family medication tracker delivered as an installable Progressive Web App (PWA). It helps households manage medications together: each patient sees their doses for the day and confirms when they've taken them, while a caretaker oversees every patient in the family group — managing medications, schedules, inventory, and dosing on a patient's behalf. The product is built on Next.js 14, Supabase (Postgres, Auth, Row Level Security, Realtime), and the "Warm Kinship" design system, which trades cold clinical aesthetics for domestic warmth and clarity.

## What's in this folder

This folder is a self-contained reference set for the MedTrak project, suitable for sharing with stakeholders, designers, and collaborators. It brings together the product story, the design system, and the original screen designs in one place.
